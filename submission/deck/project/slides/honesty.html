ASTRA · Space Apps 202605
This is the core idea. Each investigation produces a list of evidence items that support or weaken the conclusion, and a confidence tier computed by rules anyone can read. When ASTRA can’t measure something, it says so. The AI explainer, Gemini, only restates the evidence: each statement is tagged as measured, catalogue, interpretation or hypothesis, and a grounding check throws out any number that isn’t in the data. If the AI is unavailable, a deterministic template takes over.
