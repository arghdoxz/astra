Limits and next steps

What ASTRA doesn’t do yet

Today

Aperture photometry, not PSF fitting. Simple or Gaussian-matched differencing, not ZOGY. Only 4–5 visits so far, so no period searches and wide motion errors.

Next

PSF-fit photometry and centroids from the long-wavelength detectors only. Every new SPHEREx release adds visits, so motion and variability tests get sharper on their own.

Data: SPHEREx via NASA/IPAC IRSA · Gaia DR3 (ESA) · SIMBAD (CDS) · CatWISE · SkyBoT. AI: Google Gemini explains results in the app; an AI coding assistant helped write the code.

We want to be clear about the limits. ASTRA uses aperture photometry and simple image differencing, and SPHEREx has only a few visits to each spot so far, so motion uncertainties are large and we make no period claims. The good news is that this improves by itself: each new SPHEREx release adds visits, and ASTRA pulls them live. Thank you.
